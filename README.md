## Projects

### Alchemy Game *(original concept, in development)*
A cozy alchemy and potion-making game inspired by Stardew Valley, built in **Godot 4** with **GDExtension**. The core systems are designed with discrete math:

- **Prime numbers** as ingredient identifiers
- **Modular arithmetic in Z₁₁** to keep effects bounded
- **Finite linear algebra** to model how each process transforms ingredients
- Four alchemical kingdoms (**Oros, Bastos, Espadas, Copas**) and four processes (**Caldero, Sublimación, Maceración, Calcinación**)
- Five formal entities with five invariants, documented in a formal design document
- **Data-driven architecture** with JSON

**Stack:** `Godot 4` · `GDExtension` · `JSON`

### Stardew Valley Mod: Dynamic Economy *(in development)*
A mod that changes item prices according to the season and the year, adding a layer of strategy to the farm economy.

- Category-based model: wines/juices, preserves, fresh crops, animal products, honey/flowers, fish/seafood
- Seasonal multipliers and difficulty tiers
- NPC dialogue as an in-world hint system
- Naturally touches on supply and demand, diversification and market seasonality

**Stack:** `C#` · `SMAPI`
**Links:** [Repository](#) · [Nexus Mods](#)

> Along the way I've also decompiled vanilla game code with **dnSpy** to replicate the logic of `WateringCan.DoFunction`, recreating watering particle effects with `TemporaryAnimatedSprite`.
